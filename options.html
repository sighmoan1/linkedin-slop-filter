Less slop. More substance.

Fold formulaic LinkedIn feed posts. Reveal any post with one click.

Start Ollama and download the model first. No tunnel or API key is needed. Only localhost or 127.0.0.1 is allowed. Local post text is limited to 2,000 characters and the rubric to 1,200.

Local confidence is a number generated by the model, distinct from Jev probability. Neither an 80% score nor a cutoff establishes 80% accuracy on your feed. Evaluate useful posts wrongly hidden before relying on a threshold.

When enabled, visible feed post text goes to the selected provider: loopback Ollama for local models, or the selected cloud API. Messages, comments and profile details are not collected. Keys stay in this Chrome profile's extension storage; they are not synced. Classification is a style judgement, not proof of AI authorship. Cloud API usage is billed separately.
