How do I get an OpenAI key?

Start Ollama and download the model first. No tunnel or API key is needed. Only localhost or 127.0.0.1 is allowed. Local post text is limited to 2,000 characters and all definitions together to 6,000. Local scores are the model's self-reported confidence, not calibrated probabilities.

Categories

Every post is scored against each switched-on category in a single request, so a post can fit more than one. A category applies when its score is strictly above its threshold. Then Hide folds the post, Highlight marks it, and Show on chip only names it on the post's chip. Off categories are not asked. More categories can cost more per post. Changing a definition or switching a category on rescores posts; changing a name, action or threshold does not.

When enabled, visible feed post text goes to the selected cloud API or loopback Ollama service. Messages, comments and profile details are not collected. Keys stay in this Chrome profile's extension storage; they are not synced. Scores are a judgement of style and substance, not proof of AI authorship. API usage is billed separately.

Testing sends one tiny request to the provider with the key shown above, even if it is not saved yet. It checks the key, your credit and access to the model together, and uses a very small amount of API credit.

Scores are remembered on this computer for up to 30 days (up to 2,000 posts) so the same post is not billed twice, even after Chrome restarts. Only a hash and the scores are kept, never the post text. Changing provider, model, endpoint or a definition starts fresh scores. Local Ollama scores last for this browser session.
