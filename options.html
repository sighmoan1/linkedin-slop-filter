Start Ollama and download the model first. No tunnel or API key is needed. Only localhost or 127.0.0.1 is allowed. Local post text is limited to 2,000 characters and the rubric to 1,200.

Local confidence is a number generated by the model, distinct from Jev probability. Neither an 80% score nor a cutoff establishes 80% accuracy on your feed. Evaluate useful posts wrongly hidden before relying on a threshold.

Categories

Every post is scored against each category in a single request, so a post can fit more than one. Tick Fold to hide posts that score above the threshold in that category. Others only add a mark to the score chip when the model rates them 50% or more. More categories can cost more per post. The local Ollama model is only asked about Slop. Changes apply when you press Save settings; changed definitions are rescored.

When enabled, visible feed post text goes to the selected cloud API or loopback Ollama service. Messages, comments and profile details are not collected. Keys stay in this Chrome profile's extension storage; they are not synced. Classification is a style judgement, not proof of AI authorship. API usage is billed separately.

Testing sends one tiny request to the provider with the key shown above, even if it is not saved yet. It checks the key, your credit and access to the model together, and uses a very small amount of API credit.

Scores are remembered on this computer for up to 30 days (up to 2,000 posts) so the same post is not billed twice, even after Chrome restarts. Only a hash and the score are kept, never the post text. Changing provider/model/endpoint/rubric starts fresh scores. Local Ollama scores last for this browser session; cloud scores keep the existing 30-day cache.
