How do I get an OpenAI key?

When enabled, visible feed post text is sent to your selected API provider. Messages, comments and profile details are not collected. Keys stay in this Chrome profile's extension storage; they are not synced. Classification is a style judgement, not proof of AI authorship. API usage is billed separately.

Testing sends one tiny request to the provider with the key shown above, even if it is not saved yet. It checks the key, your credit and access to the model together, and uses a very small amount of API credit.
