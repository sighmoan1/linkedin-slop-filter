Set up LinkedIn Slop Filter

The extension asks an AI model to judge each post, so it needs an API key from one provider. Pick one of the two below. You pay the provider for what you use, separately from any chat subscription. At the launch prices the providers have published, scoring a post is a small fraction of a cent, but prices can change, so check them with the provider.

OpenRouter (Jev), the defaultOpenAI DecisionsCheck it works

Option A: OpenRouter (Jev)

  1. Create an account or sign in at openrouter.ai.
  2. Add credit on the Credits page. Credit is a deposit that is used up as you make calls. You can top up by hand or switch on auto top-up. Leave auto top-up off if you want a hard ceiling on spending.
  3. Create a key on the API keys page. Name it something like "LinkedIn Slop Filter". If the form offers a credit limit for the key, set one so it cannot spend more than you choose. Copy the key straight away, because providers usually show it only once.
  4. Paste it into OpenRouter API key in the extension settings. Make sure Decision provider is set to Jev · OpenRouter.
  5. Press Test OpenRouter key, then enable filtering and save.

Jev is a new model, released in early access on 15 September 2026, and the extension uses the endpoint's alpha path with model typesafe/jev-1.13. Access, pricing and the model name can change. Read OpenRouter's Jev announcement for the current details.

Option B: OpenAI Decisions

  1. Use the API platform, not ChatGPT. Sign in or create an account at platform.openai.com. A ChatGPT subscription does not include API usage; API usage is billed separately.
  2. Set up billing on the billing page. If you buy prepaid credit, a small balance with automatic recharge off limits what can be spent.
  3. Create a secret key on the API keys page. Name it something like "LinkedIn Slop Filter" and copy it straight away, because it is usually shown only once.
  4. Paste it into OpenAI API key in the extension settings and set Decision provider to OpenAI Decisions · GPT-6 Luna.
  5. Press Test OpenAI key, then enable filtering and save.

The Decisions API is in public beta and the extension uses model gpt-6-luna. Read OpenAI's Decisions guide for the current details.

Check it works

Press Test key under the key you entered. It sends one small request, in the same format the extension uses on your feed, with the key as typed, so you do not need to save first. It uses a very small amount of credit.

What is sent and what it costs

  • When filtering is on, the text of posts on your feed is sent to the provider you chose. Messages, comments and profile details are not collected.
  • Your key is stored only in this Chrome profile's extension storage. It is not synced and is never given to the LinkedIn page.
  • Use a dedicated key with a spending limit where the provider allows one. The extension also stops after a set number of requests per browser session (100 by default, adjustable in settings).
