Set up LinkedIn Slop Filter

Choose a provider to check posts against your rules. For a cloud provider, follow the steps below to add an API key. API requests are charged separately from chat subscriptions. You can also use Ollama on this computer without an API key; open Provider in settings for setup instructions.

OpenRouter (Jev), the defaultOpenAI DecisionsTest your connection

OpenRouter (Jev)

  1. Create an account or sign in at openrouter.ai.
  2. Add credit on the Credits page. Requests use this balance. Check the current prices before adding credit. Leave automatic top-up off to control spending.
  3. Create a key on the API keys page. Name it something like "LinkedIn Slop Filter". If the form offers a credit limit for the key, set one so it cannot spend more than you choose. Copy the key when it appears.
  4. Paste it into OpenRouter API key in the extension settings. Make sure Text provider is set to Jev · OpenRouter.
  5. Press Test OpenRouter key, then enable filtering and save.

The extension uses model typesafe/jev-1.13 through the alpha endpoint. Check model access and pricing before use. Read OpenRouter's Jev announcement for the current details.

OpenAI Decisions

  1. Create an API account at platform.openai.com. A ChatGPT subscription does not include API usage; API usage is billed separately.
  2. Set up billing on the billing page. If you buy prepaid credit, a small balance with automatic recharge off limits what can be spent.
  3. Create a secret key on the API keys page. Name it something like "LinkedIn Slop Filter" and copy it when it appears.
  4. Paste it into OpenAI API key in the extension settings and set Text provider to OpenAI Decisions · GPT-6 Luna.
  5. Press Test OpenAI key, then enable filtering and save.

The extension uses the Decisions API with model gpt-6-luna. Read OpenAI's Decisions guide for the current details.

Test your connection

Choose Test OpenRouter key or Test OpenAI key in settings. This sends a sample request using the key you entered. You can test before saving. The provider may charge for the request.

The test saysWhat to do
Key worksEnable filtering, save, and reload your LinkedIn feed.
The provider rejected this keyThe key is mistyped, incomplete or revoked. Create a new one and paste it in full.
The account has no creditAdd credit with the provider, then test again.
Rate limited, or out of creditCheck your billing and balance. If they are fine, wait a minute and try again.
Not allowed to use this model, or could not find itCheck model access in your provider account and the documentation linked above.
Not in the expected formatTest again. If the response still has the wrong format, report the problem on the project page.
Could not reach the provider, or no answer in timeCheck your connection and any VPN or network filtering, then try again.

Data and charges

  • When filtering is on, the extension sends post text to your chosen provider. Ollama checks text on this computer. Optional image checks send resized post images and captions to OpenRouter. Messages, comments and profile details are not collected.
  • Your key is stored only in this browser profile's extension storage. It is not synced and is never given to the LinkedIn page.
  • Use a dedicated key with a spending limit where the provider allows one. The extension also stops after a set number of requests per browser session (100 by default, adjustable in settings).

More detail is in the project README.
